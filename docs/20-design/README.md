# Design Specification

Design system, brand guidelines, and UX flows for the Decision Intelligence Engine.

---

# Architecture Direction

The MVP is a headless engine with a command-line interface ([ADR-018](../90-records/decisions/02-mvp-design.md#adr-018-the-mvp-is-a-headless-engine-with-a-cli)).

The web application and its interface views follow in [Phase 2 — Advanced Decision Engine](../00-product/roadmap/03-phase-2-advanced-decision-engine.md#web-app-and-api). The specifications in this folder define the design system, brand identity, and user flows for that web application.
