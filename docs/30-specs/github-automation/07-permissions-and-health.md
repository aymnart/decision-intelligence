# GitHub Permissions

Minimum permissions:

Repository:

Read/write

Issues:

Read/write

Projects:

Read/write

Pull requests:

Read/write

Contents:

Read/write

Dangerous actions require approval.

# Human Approval Required

Before:

Create repository

Delete repository

Merge PR

Push to main

Change permissions

Delete branches
