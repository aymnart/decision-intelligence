# Milestones

Milestones represent roadmap phases.

Example:

```
MVP

Beta

Public Launch

Growth

Scale
```

---

# Milestone Structure

Each milestone contains:

Goal

Description

Success criteria

Issues

Deadline

---

Example:

```
Milestone:

MVP

Goal:

Validate core product.


Success Criteria:

- Users can create projects
- Council can make decisions
- Reports generated

```
