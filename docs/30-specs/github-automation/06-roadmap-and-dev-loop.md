# Roadmap Integration

The roadmap becomes GitHub milestones.

Example:

```
ROADMAP.md

↓

Milestones

↓

Issues

↓

Execution
```

---

# Automatic Issue Updates

The AI can update issues.

Examples:

When implementation starts:

Add:

```
Status:
In Progress
```

When blocked:

Add:

```
Blocked by:
#25
```

When complete:

Add:

```
Completed

Test results

Documentation updated
```
