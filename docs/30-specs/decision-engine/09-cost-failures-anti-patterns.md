# Cost Optimization

The Decision Engine controls AI spending.

Rules:

Simple task:

```
Fast model
One expert
```

Complex architecture:

```
High reasoning model

Full council
```

---

# Failure Handling

If consensus is impossible:

Conditions:

```
Agreement < 60%

OR

High uncertainty

OR

Missing information
```

Actions:

1. Request clarification

OR

1. Gather more information

OR

1. Present multiple valid options

---

# Anti-Patterns

Never:

- use one model as every expert
- force agreement
- hide uncertainty
- skip tradeoffs
- make decisions without context
- store only the final answer
- ignore previous decisions
