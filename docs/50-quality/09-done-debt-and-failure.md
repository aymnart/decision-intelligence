# Definition of Done

A task is complete only when:

```

Code written

↓

Tests pass

↓

Documentation updated

↓

Architecture reviewed

↓

Security checked

↓

Decision recorded

```

---

# Technical Debt Management

The system must track:

- shortcuts
- compromises
- known risks

Create:

```

TECH_DEBT.md

```

---

# Failure Philosophy

Failures are information.

Every failure should improve the system.

Store:

- what failed
- why
- fix
- prevention

---

# Golden Rule

The Decision Intelligence Engine must produce software that a world-class engineering team would be proud to maintain.

The goal is not generating more code.

The goal is generating better software.
