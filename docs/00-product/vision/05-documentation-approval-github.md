# Documentation Philosophy

Every project should eventually contain:

PROJECT.md

ARCHITECTURE.md

DESIGN.md

STACK.md

ROADMAP.md

DECISIONS.md

CONTRIBUTING.md

WORKFLOWS.md

PROMPTS.md

Every generated file should become permanent context.

---

# Human Approval

The AI should never automatically:

Create repositories

Delete repositories

Push commits

Merge pull requests

Delete files

Run dangerous commands

Spend money

Purchase services

These require approval.

---

# GitHub Philosophy

GitHub is not storage.

GitHub is project management.

Every issue should have:

Purpose

Context

Acceptance Criteria

Dependencies

Priority

Labels

Milestone

Estimated Complexity

Definition of Done
